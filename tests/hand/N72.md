# N72: a fix can read the words typed earlier

Gap (n102, round 37 team chat): the fix note "each row: name, small grey preview under" reached all four sidebar
rows but filled them with made-up copy ("#marketing", "New mockups in review"), although the row words had been typed
before the first build ("#design / New logo is up, Ravi Patel / sounds good, ..."). A fix run only saw its own notes.

## What was built
- **Earlier notes reach the fix** (`earlier.ts earlierNotes`, `earlierNotesBrief`, wired in `run2.ts`): every run
  already writes its typed notes to its run folder. A run on a built page reads them back from the runs before it
  (newest four, words once, each with the spot it was typed) and the build is told: copy a fix needs comes from the
  earlier note typed nearest that spot, a "/" or "," list gives one member each in order, never made-up words.
  Saved per run as `earlier-notes.json`.
- **Made-up copy is measured** (`inventedCopy`, zero tokens): text new with the fix, not on the page before, with two
  or more words (and most of them) that nobody typed, now or earlier, is a failure sent to the repair rounds with the
  earlier note nearest it. Notes asking for sample or placeholder copy are exempt. It is not put back (a made-up row
  is better than an empty one); only repaired.
