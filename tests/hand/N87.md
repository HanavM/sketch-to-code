## Round 36 roll-up (c1-c5 from n86, e1-e5 here)
Mean likeness **72.3** (c 72.4, e 72.2); median **19 strokes**, **66.5 words**, **8.1 minutes**; 9 of 10 pages
needed one fix round; 1.24M billed tokens. Below rounds 34 (79.5) and 35 (77.9). Strokes stay under 20;
**words are the failing number**: every app page with a list or table needed 60-130 words because the
row contents can only be typed.

## What went wrong (gaps found)
- **Row content has to be typed in full** (e2, e3, e4, e5): five transactions, a 4x7 hours grid, seven
  emails, five toggles — 64-131 words each. Strokes can't carry it. Lead: placeholder rows ("5 rows like
  this" with no words) built with plausible filler, or paste/import of a short list, so words count drops.
- **"Rows like this" loses the drawn row** (e2, e4): the first row was drawn as square, name, middle
  column, amount on one line ~58px tall; the build stacked the middle text under the name and made rows
  ~78-115px tall. A fix restored it both times. Lead: the drawn first row is the template for every row,
  keeping its columns and height.
- **A tap above a line inside a box fills the whole box** (e3): a grey tap in the table's header strip
  made the whole table grey (in e1 the same move made a blue top band correctly, so it is inconsistent).
- **A box drawn in a dark pen with no tap is built filled** (e1 barcode, e3 pager buttons; known n78).
- **A fix note leaks to a nearby element** (e3): "white boxes, thin grey border" for the pager buttons
  also turned the purple Submit button white.
- **A style note in a gap binds to one card** (e2): "small grey label, big number under" bound to one
  of four stat cards, which came out grey with the order flipped; a fix fixed all four.
- **Numbers in notes get printed** (e3): "progress bar 82%" printed a huge 82%.
- **Invented parts** (e4: an Inbox header with a search bar and gear; e1: a paper-plane icon for the
  drawn arrow after the fix asked for a plain arrow glyph).
- **Things built lower than drawn** (e2 title +22px, e5 rows drift so the last row overflows the card).
