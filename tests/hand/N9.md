# n9: show which mark each note belongs to (goal 2026-10-27)

What was built (branch try/n4-look-fix):

- **A thread from every note to its mark.** While you draw, each note chip has
  a dashed amber thread to the mark it is about, and that mark gets a faint
  outline. The bar says it in plain words when a note lands ("on this box",
  "on this ring", "on this line", "whole sketch"). Before, every note in a
  busy sketch said "on these 8 strokes" and you only found out which mark it
  went to from the build.
- **Same rule on both sides.** The rule that picks a note's mark
  (`noteFocus`) moved from the pipeline into `@s2c/ink`, so the overlay runs
  exactly what the build runs, and the overlay now sends the marks it shows.
  What the thread shows is what codegen is told.
- **Drag a note onto the right mark.** Drag a chip and drop it on another
  mark; the thread jumps there at once. Drop it in empty space and it becomes a
  whole-sketch note. A plain click still opens it to edit.
- **A diagonal covers its ink, not its box.** A long diagonal stroke's
  bounding box no longer swallows notes typed beside it (the page-tall band
  was grabbing the big "09" note).

Re-sketch of the diagonal split: same 9 strokes as n8, same notes typed at
the same points, then I looked at the threads and dragged 5 notes onto the
marks I meant (nav and colours to whole sketch, subtitle to its line, badge
into the ring, 09 into the big box). No fix note needed after the build.
