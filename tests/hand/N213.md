# n213: a fix that breaks one part puts back only that part

Found in n210 (round 46 c4, tennis club): two fix notes read right ("white lines only", "3 tiles, one per stat, big
number"), but one line of old text went away when it was split into tiles, the whole fix was thrown out, and the page did
not change. Counted over every saved fix so far: 5 of 75 were put back whole (4 emptied text, 1 ran words together). Two of those
5 are already exempt since n165 and n190.

## What was built (zero tokens)
- **Split up is not emptied** (`lostCopy`, `fixcheck.ts`): a line of four or more words is not lost when 70% of its words now
  read in pieces of text that were not on the page before. Words already on the page do not count.
- **Only that part goes back** (`partback.ts`, `run2.ts`): the fix is split into edits against the page as it was. Only edits
  holding the broken words go back: emptied words from the old side, an extra copy from the new side, words that now touch
  other words from the edit at or just above them. An edit that is not a whole piece of the tree gives up. The page is then
  checked again; if that did not clear it, the whole put-back runs as before. No model is asked.
- **A fill that stayed takes nothing with it** (`onlyFillStayed`), found live on this step's first replay: "white lines only"
  read on a box inside the green court, the green stayed, and that one miss threw away the other note's big numbers. A fix
  with more than one note now keeps the rest and says which fill stayed. A fix with one note still goes back whole (n37).

## Did it help
- **Tennis with the same fix notes: 65.0 to 87.4 and 85.6.** The big numbers are there. Note that the page already got 87.0 and
  86.1 with no fix after n212, so this shows the fix now lands, not a higher score. This page has been seen, so it cannot count toward done.
- **Not seen live: the part put-back itself.** It never fired in these five fix replays, since none of them broke a part (one
  fired the fill-stayed path before that path was built, which is how it was found; the runs with it did not hit it again).
  It is covered by unit tests and a real git tree test, not a live run. It is rare by nature, about 1 fix in 15 before this step.
- Chess night fell from 78.7 to 59.5. That is not this change: the first build printed "MATE HUGE BOLD CAPS, MATE OUTLINED ONLY"
  (open lead n164) and shaded the cream squares, and the heading came out small after the fix.
