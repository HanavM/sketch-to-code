# n179: notes that describe cards are never printed; a page drift is traced in its own column

Found in n178 (round 43 e4 pet adoption, replay):
- **Try 1** printed "pet cards: tinted picture top (...), name bold, age · breed under" as the first card's name and
  "Biscuit, Juno, Pepper, Otis, Maple, Rio" as the second's.
- **Try 2** built the page about 40px below the drawing.

## What the run records showed (n179 control replay, the tool as n178 left it: 74.8)
- The printed notes came from the tool itself: the look-alike check (n69) gave card 1 the description note and card 2
  the whole name list as "their own typed words", and the repair was told to "put exactly those texts on those
  items". It did, broke other checks, and was put back, so the drift fix in the same repair was lost too.
- The drift message for the filter checkbox (far left) traced it through the heading's line over the cards (another
  column). The repair took that space out of the cards' column: cards went from 8px low to 23px high.

## What was built
- `typedcopy.ts` `specNote`: a note "<kind>: <how each looks>" whose words after the colon are lower-case part and look
  words is a description of every item of that kind, never copy. Told to the build, checked on the page (its lead
  "tinted picture top" must not appear). A colon note with names in it ("filters: Animal (Dogs, ...)") is not one.
- `typedcopy.ts` `nameList`: three or more short capitalised names with commas are one name per item, never printed
  as one line. Told and checked.
- `rowwords.ts` `spreadNameGrid`: a name list as long as a drawn grid of look-alike boxes (2 rows of 3) is one name
  per box in reading order; neither note becomes one card's own words any more.
- `shapemark.ts` drift tracing: the line above a box that is used to place the drift must lie over the same column.
  The checkbox is now traced to the header rule, so its fix is the sidebar's own top gap.
- Tests: `packages/pipeline/tests/n179-spec-notes.test.ts` (7, on the real pet notes and marks); the column test
  fails on the old code.
