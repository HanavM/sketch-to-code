  under" built as dark rules with no text; a fix put the text in but kept the bars, price on the same line).

- **A slanted line is built as a thick bar** (c1: kite strings became wide navy rectangles, the line's
  bounding box filled). One fix note made them thin slanted lines. Lead: a lone diagonal pen line is a line.

  line, left edge" next to the subhead bound to the headline div and joined CHECK MATE onto one line,
  running off the page). A second fix round changed nothing at all (10 s read, page unchanged).
- **A two-line stacked heading sits low** (c4: MATE built over the subhead; drawn lines read as bottoms).
- **A pill note with a date was built as a date chip** (c5: "Sunrise · 14 March" became "14 / Sunrise").
- **A pen box round a big word kept a thin border** (c5: 10K boxed) until a fix.
- **A bottom line under the toolbar** (c5 footer): the note bound to the mountains, the line became a bar
  and the text was cut short. Lead: the toolbar should step aside for strokes near the bottom.
