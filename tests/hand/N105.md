# N105: a sidebar note of name / preview pairs split by commas fills each row with its own name and preview

Gap (n104, round 37 team chat): the sketcher gave the four sidebar rows in one note, the short way:
"#design / New logo is up, Ravi Patel / sounds good, #support / 3 new tickets, Lena Ortiz / call at 2?". The tool
split it only at the slashes, so the rows came out as "#design", "New logo is up, Ravi Patel", "sounds good,
#support"...: each row held one row's preview and the next row's name. Every build of n104 got the sidebar wrong.

## What was built
- **Name / preview pairs** (`rowdata.ts pairRows`): when a slash list has 3+ pieces, a comma in every inner piece
  and none in the two outer ones, and each name after a comma is short (4 words or fewer), it is read as rows of
  (name / preview) joined by commas: one row per pair, the name and its preview as two cells (name first and
  stronger, preview under it). Anything else is split by slashes as before.
- The existing row-data brief and page check apply unchanged: every name on the page, in typed order, and no name
  sharing a piece of text with its preview.
