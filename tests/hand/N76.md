## What went wrong (gaps found)
- **Page taps on both sides of a full-width line still make one diagonal fade** (c1, known as n67): sky
  above, green band below became a corner-to-corner gradient over everything, and the band was built
  50px high and 100px short of the bottom. The fix note ("band starts at this line, to the bottom") was
  placed in empty space ("placed here"), bound to nothing, and was built as a second stripe: 52.8 final.
  Leads: (a) n67, the divider split for the page itself; (b) a fix note dropped next to a built block
  should bind to the nearest block, not become new content.
- **"Outline only / no fill" strips the border too** (c3, c4): the fix check says "make it transparent
  with no border or shadow", so a hollow button loses its outline (c4) or the repair is refused and the
  fill stays (c3, "the fix kept the fill"). A box drawn in a coloured pen with no tap was built as a
  filled button both times. Lead: a pen-coloured box with no tap is an outline box (border in the pen
  colour, no fill), and "no fill" keeps the border.
- **A pen-coloured area box round a giant word became a filled card** (c2): SCOOP sat on a plum slab;
  one fix note removed it (good fix). Lead: n14's area-box rule should hold when the box is drawn in a
  colour.
- **Typed copy cut at a comma** (c5): "Pre-order, 38, bold" built as "Pre-order" at 36px; the fix note
  ("text is Pre-order, 38 at normal size") was "placed here" and did nothing.
- **Nav words not spread** (c4): "Classes Teachers Pricing Sign in" built run together with no gaps,
  "Sign in" wrapped; the fix note joined them on one line but kept no gaps. A two-word item breaks the
  3+-items spread rule.
- **A row of labels under a row of circles is also built as a rule** (c5), and the labels came out
  tiny and 30px high; the label note bound to "3 marks" (labels line, rule and row area).
- **No way to say "repeat"** (c2, c5): 8 even stripes needed a sentence; five same-size circles needed
  five strokes. Lead: a repeat gesture (draw one, tick a count) would save strokes on both.
- **Moon phases**: shading only came with a fix, lit side reversed (lead only; it is a picture detail).
- **The second line of a two-line heading is dropped** (c2): the note bound to the first line only
  ("on this line"), so "Churned by hand, every single morning." was one smaller line.
