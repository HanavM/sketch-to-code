# N102: a fix note about a set reaches every member and keeps each one's words

Gap (n100, round 37 team chat): the fix notes "chat bubbles: message text only, time small above" and "each row: name,
small grey preview under" either reached one member only, or (with n100's set brief) emptied the grey bubbles and
copied each name into its preview line. Nothing on the page checked it, so the broken fix was kept.

## What was built
- **Set notes reach every member** (`fixcheck.ts isSetNote`, in `fixBrief`): a fix note that opens with a set
  ("chat bubbles:", "each row:", "every card:", "all events:") tells the build it covers every member of that set,
  and that each member keeps exactly its own words (never emptied, never another member's copy).
- **Copy is kept, measured on the page** (`lostCopy`, `copiedCopy`, in `verifyFix`, zero tokens): after a fix on a
  built page, copy that was there before and is now gone with nothing written in its place is a failure, and copy
  that now shows in more places than before (a name pasted into a preview) is a failure, unless the note asked for
  words to go or for more of them. Both go to the repair rounds; a fix still failing them is put back, like n37's
  overlap and no-panel checks.
