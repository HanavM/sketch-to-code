# n7: drawn means placed (goal 2026-10-27)

What was built (branch try/n2-shape-vocab):

- **Shape marks.** A stroke that is a plain box, a straight line or a ring is
  read from the ink (`packages/pipeline/src/shapemark.ts`) and kept as its clean
  geometry: the box, the line's two ends, the ellipse. It sets where things go
  and how big, and it never becomes an SVG path, a scaffold or an instant-render
  mount, so the person's wobbly ink is never pasted into the page. Codegen is
  told what each one stands for (a box is the block at exactly that box, with no
  frame unless it is a card, button or field or a note asks; a level line is a
  row of text centred on the line, a rule or an underline; a ring is a clean
  circle). A drawn depiction ("a sun") keeps its paths, but a box, line or ring
  inside it is handed over as the clean shape.
- **Drawn boxes are checked where they land.** After the build, every drawn box
  and ring is matched to the built element of about its size; one more than a
  few px off fails the check with how far and which way ("the toggle drawn at
  (1112,169) sits 22px too low"), and the existing repair round fixes it.
