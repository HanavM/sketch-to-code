## What went wrong (gaps found)
- **A pen box round a big word is still filled solid** (c2 white WAVE box became a white block with no
  word; c5 black box round "40" became a black block with a white 40). Fix notes worked both times, but
  the WAVE then shrank to ~2/3 of its box. Lead: a pen box with a word note and no tap is an area for
  that word (n14/n17 rule did not hold for a white or black pen box with no tap).
- **A white-pen box with no tap became a solid white button** (c4 "Book a night" is an outline button).
  The fix note "outline only" landed on nothing ("placed here") and the builder applied it to the
  planets instead, hollowing them; a third run refilled them. Lead: a fix note that binds to no mark
  should go to the nearest mark, never to an unrelated group.
- **A tap in the middle of a filled ring adds a dark inner disc** (c4 all four planets got a second,
  darker disc where the tap was). Lead: a tap is a fill, never a mark.
- **Small coloured rings built as squares** (c3 nine chips): rings of r=15 came out as square chips
  under a faint disc. A plural fix note "all chips round" reached only the first cookie's chips
  (same gap as n132).
- **Circles clipped to a box edge** (c4 moon and planets have flat sides; the moon's glow is cut off).
- **"price under" ignored** (c3): "Classic chip, £2.50 under" was built on one line until a fix.
- **A note on a line inside a big filled panel binds to the panel** (c5 tagline and footer; same as n99).
  Dragging the chips onto the lines fixed it (2 note moves).
- **Footer spread** (c1): footer text built centred, below the drawn line; the fix spread it out but
  still ~40 px low. Headlines on c1, c3, c4 built 25-60 px off their drawn lines.
