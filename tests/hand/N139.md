## What went wrong (gaps found)
- **A mid-colour pen box with no tap is filled** (e1 grey list box became a grey panel; e5 purple-pen
  "Team" card became solid purple although the note said "pale fill"). The n131/n134 outline rule covers
  light pens only. Lead: a box drawn in any pen with no tap inside a filled area is an outline (border),
  unless a tap or note says fill.
- **A fix note on a panel reaches only the element under it** (e1 "no fill" cleared one row of six; a
  whole-sketch note was needed). Same family as n132 (plural fix notes).
- **A list note typed in empty space binds to a far box** (e2 ingredient list, 130 px from the photo box,
  was built inside the orange photo). Took a fix to move it. Lead: a note with no mark under it stays
  where typed (n29 rule did not hold for a long note whose chip overlapped the box edge).
- **A note on a full-width divider line is centred or blown up** (e2 "Pantry" centred; e4 a small title on
  the header divider became a 60 px heading). Lead: a note on a long thin rule is text above the rule at
  the typed spot, at a normal size.
- **A fix note that shrinks a heading also moves it** (e4 title went from left to right edge).
- **Two parallel long lines read as one box** (e3 the two horizontal roads framed a "box", and the road
  note bound to it). The roads still built, but the dark route polyline drawn along them was dropped twice,
  even with a fix note. Lead: a long open polyline is a path/route, never a shadow or box edge.
- **Small rings built as squares** (e3 map markers, blurred squares; same as n138 c3).
- **Literal direction words** (e2 "steps:" printed; second step cut to "Fold in flour and sugar").
- **A tap inside a ring still shows as an inner dot on the sketch** (e2 method circles; built right).
- **Group notes bind to one mark** (e5 "steps 1 Account, 2 Plan, 3 Pay" bound to ring 2; built right anyway).
