# n24: a page that drifts down is fixed at the top; repairs never keep a worse page; every row gets every part (goal 2026-10-27)

## Built this step
- **The cause of a drift is named at the top.** When the top box of a column
  (the first toggle) is off and the boxes below only follow it, the check now
  says the whole page from there down sits N px low, measures the drawn gap
  under the nearest drawn line above it (the tabs line) against the built one,
  and tells the repair to take N px OUT of the space above it, never to add
  space or push it down (`topDrift` in `shapemark.ts`).
- **A box riding the same drift is not moved on its own.** A box elsewhere that
  is off by the same amount as a drifting box above it is told it lands when
  the top is fixed (so the fix is not doubled).
- **A repair that moves drawn boxes further off is put back.** Each repair turn
  starts from a saved copy of the page; if the round does not raise the pass
  share and the drawn boxes end further off in total (`marksMiss`), the page
  from before the round is restored and re-verified (`run2.ts`).
- **Boxes moving closer is progress.** A repair round that leaves the pass
  share flat but brings the boxes clearly closer (12 px or more in total) earns
  one more round instead of stopping on "no improvement".
- **Every row gets every part a note names.** A note like "4 rows, title + grey
  line: ..." now tells codegen that each row has a title and a grey line, with a
  short placeholder line where none was typed (`rowparts.ts`).

Tests: shapemark (2 new), rowparts (4 new). Build clean; pipeline suite 1020
pass, 1 fail (library home-dir test, environment only).
