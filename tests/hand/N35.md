## What went wrong (gaps found)
- **Fix notes after a build make it worse** (c1, c2, c4): a note on a built element runs a 7-30 s direct
  edit with no page check. c1 "two lines: NORTH / LIGHTS" broke the heading onto the date; c2 "one line,
  below heading" moved the subtitle *up* into the heading; c4 "no panel behind bars; pink at top" painted
  the panel pink-violet instead of removing it. Only c3 (a size fix) helped.
- **A fix note binds to the container, not the parts it names** (c4): the note was about the bars, landed
  on the wrapper div, and the edit changed the wrapper.
- **Big two-line headings 170px apart are not one heading** (c1): the second heading line grouped with the
  date line below it, so the date note covered both, and NORTH LIGHTS came out on one line.
- **A three-line heading at 72px pitch: the note took only 2 lines** (c2); the third line was left free and
  the subtitle was built on top of it (overlap).
- **Two heading lines 80px apart: note took 1** (c3), and the unnoted second line got **invented body copy**
  ("Each project begins with light...").
- **A red underline drawn under a short link grouped with the paragraph line above** (c3): the link was built
  as huge red display text (sized from the pitch, coloured from the ink).
- **A note typed 55px above a line is "placed here", and a placed note can't be dragged onto a mark** (c1,
  first try): dropping it always gives "whole sketch" (the drag re-reads the drop with the note's old
  "whole sketch" rule). Had to delete and retype (bench now has `deleteNote`).
- **Page taps aren't shown as the page colour on the sketch** (c1): the two dark taps left the canvas grey.
- **A drawn pill with angled ends was pasted as a hexagon** (c5): the button's ink outline became an SVG shape.
- **A nav line drawn 520px wide spread to the page edges** (c5); a centred heading built narrower than drawn.
- **No way to draw a repeated row of bars** (c4): 16 bars would take 16 strokes; an area box plus a note
  built them, but the area box became a grey panel and the page drifted 80px down.
- **The soft aurora band has no mark** (c1): a typed note "soft teal-violet aurora glow band" was ignored.
