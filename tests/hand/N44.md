# n44: a bare line under a heading is its next line; italic means italic

## What was built
- **A bare line under a heading line is that heading's next line** (packages/ink/src/textmark.ts `lineStacks`,
  `StackOpts.notesAt`): stacks now know where notes were typed. A level line with no note on or near it (48px) that
  sits under a noted heading line at heading pitch, same left edge, may run up to 1.6x longer and still be the
  heading's wrap ("Buildings / that breathe.": the second line is longer). Before, the longer-line rule split them
  and the bare line got a made-up subtitle. A longer line that has its own note is still the next block.
- **A paragraph's wrap line never starts a heading**: round 32 c3's paragraph second line and the link 115px under
  it were read as a 105px two-line heading; a line held tight by another line now cannot head a stack.
- Overlay and build read the same set of notes (notes on marks and placed notes; whole-sketch notes sit nowhere), and
  the note being typed counts, so the status says "on these 2 lines" as you type the heading note.
- **Italic means italic** (codegen brief): "italic" sets font-style only, weight stays regular unless the note says
  bold; a regular heading drawn as one long line is sized up to span it.
- Unit tests: packages/ink/tests/barewrap.test.ts (5 cases, round 32 c3 strokes as drawn).
