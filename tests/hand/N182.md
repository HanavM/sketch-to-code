# n182: named card tints stay the tints a person asked for

Found in n181 (round 43 e4 pet adoption, replay): the note "pet cards: tinted picture top (peach, sage, blue, lilac), ..."
names four soft tints. Each run the builder chose its own value for each word: one run soft pastels, the next a
saturated mint for sage and yellow for peach (65.3). Nothing checked the colours.

## What was built
- `tints.ts` `tintListOf`: a note that asks for tints (tinted, pastel, soft, pale, light, muted) with a bracketed (or
  "tints:") list of two or more colour words is read into fixed soft values from one general table of colour names
  (the same table for every page; nothing per page). Notes without a tint word, or lists that are not all colours
  (filter options, names), stay as they were.
- Brief: the tints are given as exact values, in typed order, cycling over the repeated items (item 5 is the first
  colour again); never brighter or a different hue; colour words never printed.
- Check `verifyTints`: the filled blocks on the page (60x40 or bigger, a real colour) must include every named tint, and
  blocks the size of the tinted ones may not carry a drifted fill; the fault names the values to use.
- Tests: `packages/pipeline/tests/n182-named-tints.test.ts` (6).
