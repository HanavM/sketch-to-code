# n212: a box with a same-pen line through it is lines, never a filled card

Found in n210 (round 46 c4, tennis club): a green court, a white box on it and a white net line through it. The build
made a solid white card with two invented blurbs. A fix note read right but was put back whole (n213), so the page stayed at 65.0.

## The lead was too broad, so the rule changed
The lead said "an untapped pen box on a filled box is an outline". A count over 177 earlier sketches says no: 73 such
boxes, mostly fields, buttons and pale cards that mean what they look like. The tell here is different: **a filled white
box would hide a white line, so a person who draws both means lines.** The rule: a box at least 100x60, no tap, no note of
its own, on a filled surface it shows against, with a same-pen straight line crossing its edge or spanning most of it.
Run over all 177 sketches with the real shape reader, it fires on this box and no other.

## What was built (zero tokens)
- **The reading** (`linesOnlyBox`, `inkcolour.ts`): told as lines only: a 2px border, see-through, no words.
- **Never traced** (`intent2.ts`): the first live run (73.0) still built a white block, because the box was read inside
  a depicted "panel" and traced as a filled outline. It now stays a box mark, like n134's frames.
- **Checked on the page** (`linesOnlyBuilt`): a block filled the pen colour fails, words inside it fail, no border fails.
- **A direction word after a count** (`repeatmark.ts`, `rowdata.ts`), found on the same page: "x3 stacked: a / b / c" made
  one tile and printed "stacked:". The number in "14 coaches" was also taken as the count, so no repeat at all. A note that
  opens with the count is that count, the word sets which way copies go, slashes split the items (commas stay), and the word is never printed.

## Did it help
- **65.0 with a fix that did nothing to 87.0 and 86.1 with none**, 58 to 44 words, tokens down 32 to 41%. Not a round result:
  this page has been seen, so it cannot count toward done.
- Limits: the rule only fires with a crossing line. A lone pen box meant as a frame on a filled surface, with no line and
  no note, is still read as a filled card. Only straight level or upright lines count, so a slanted line does not trigger it.
- Still off on this page: the note "thin white border inside" no longer gets its inset frame (the earlier builds made one,
  in the wrong place). The tiles print their words small: the note gave no big number, so the 6, 14 and $39 are not big.
  The tiles came out about 8px shorter than the target's, as drawn.
