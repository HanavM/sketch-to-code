# N103: marks drawn one under another are built in the drawn order

Gap (n72 try 2, round 37 team chat): five message boxes drawn top to bottom (Mia, "On it", Ravi, "Great", image).
Ravi's words were typed last, after the image, and the first build put Ravi's bubble second, above "On it", following
typing order instead of the drawing. Nothing checked it; the layout part of the likeness fell to 0.36.

## What was built
- **Drawn order told** (`drawnorder.ts drawnStacks`, `drawnOrderBrief`, in `run2.ts`): three or more boxes with their
  own words, in the same container (smallest box holding them, or the page), drawn one under another, are a stack.
  The build is told the stack top to bottom with each box's drawn height, whatever order the notes were typed in.
- **Drawn order checked** (`verifyDrawnOrder`, zero tokens): each stacked box's words are found on the page; a pair
  drawn one above the other but built the other way round, or a box built more than its height (at least 80px) from
  where it was drawn, is a failure sent to the repair rounds, naming both boxes and their drawn heights.
