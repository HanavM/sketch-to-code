# n22: a repair round that thinks without editing is cut short, and repairs aim without overshooting (goal 2026-10-27)

## Built this step
- **Thinking is not progress.** The watchdog used to reset on every message,
  thinking included, so a repair could think for 8 minutes. Now only tool calls,
  tool results, reply words and turn ends count, and a repair turn that goes
  180 s without an edit is stopped with the build kept (`turn-watch.ts`,
  `movesTurnOn` in `codegen.ts`).
- **Repairs run at low effort.** A repair is told the exact pixels to change;
  at default effort every repair turn this step (tries 2-4) read the file and
  then thought for 120-180 s without an edit. At low effort repairs edited in
  4-18 s and passed (tries 5, 6). Build turns keep the default effort.
- **A box pushed off by the box above it is told it follows.** Each box is
  judged by its own error (its offset minus the offset of the box above it, or
  of the card it sits in). A field that is off only because of the field above
  is told not to move on its own; a landed box below one that will move is told
  to keep its drawn top. (n20 try 3: both fields told "move 16px", both moved,
  password field and button ended 16 and 26px too high.)
- **Every box on the page is matched together**, big boxes first, and a box
  inside a card that landed off is looked for where that offset puts it (try 2:
  card 90px low, so the email box had been matched to the password field).
- **A big block exactly its size anywhere is that block, off**, not "nothing
  built near it" (try 3: card at the left edge, 429px off).
- **flow-root never beats flex on one element.** The finishing pass drops
  flow-root where flex or grid sets the display; in Tailwind's order flow-root
  won and the card meant to be centred sat at the left edge (try 3).

Tests: shapemark (4 new), turn-watch (2 new), finish-display (2 new). Build
clean; suite 1569 pass, 2 fail (root-only permission test, and a GitHub-CLI
test that needs `gh` absent; both environment only).

## Gaps found this step
- A repair at default effort thinks for minutes before editing (fixed: low effort).
- A whole page drifts down by the header's extra height; a repair can move
  boxes the wrong way and nothing says the drift starts at the top.
- A whole-sketch note describing every row ("title + grey line") is only partly
  built: the second line was dropped.
- Notes typed beside a column of small boxes bind to groups of them; typing
  inside each box was needed.
