  baseline, where the grey came from words.

## Built this step
- **A colour from the ink is never snapped.** Tapped and pen colours are now
  treated like a typed hex: the finishing pass leaves them exactly as told.
- **A single tapped colour is checked as exact** (ΔE 2.5, gradient stops keep
  the loose bar), so a white page no longer passes for a tapped pale grey and
  the miss goes to the repair round.

Tests: `packages/pipeline/tests/inkcolour.test.ts` (+1). Build and typecheck
clean; full suite 1547 pass, 2 fail as before (root-only permission tests).

Re-run of login with the fix (twice): the check now catches the white page
("the whole page should paint #f3f4f6 ... ΔE 4 away"), but the builder had
written white itself while saying it wrote #f3f4f6, and then the repair round
never started: no progress for 8+ minutes both times, no record written. Files

## Gaps found this step
- A style word in a note ("big bold") is copied into the text.
- Boxes drawn tall stop at their content height; a word fix for height moved
  them instead of growing them.
- Two short lines under each other (title, subtitle) bind to one note as a
  stacked heading ("on these 2 marks") even when their lengths differ a lot.
- The builder can report a colour it did not write.
- A repair round after a failed check can stall silently (seen twice): the
  run never ends and nothing says so. This is now the most urgent gap.
