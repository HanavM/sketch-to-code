# n270: a fix names one small thing and changes only that; a plural reaches them all

Found by the n266 redraw: "hub gold" on the clock turned the whole cream face gold, "button hollow, gold outline" lost the outline so the button vanished, and "tracks thick black" reached Bass only.

## What actually went wrong
- A note sits on whatever element is under it. "hub gold", typed on the clock's container, was read as "the clock-face container (the hub)".
- Every check passed: the note names gold and sits on that element, so gold there looked asked for.
- "Hollow" was taken as "no fill" and nothing asked for a line round it.
- A plural typed beside one track was read as that one track.

## What was built
- **The reading is told a short note leads with what it is about**, whatever it sits on, and a plural is every one of them.
- **The build is told the same per note**: only the hub changes; every track changes; hollow means no fill and a visible outline.
- **Three new checks on the page after a fix** (no tokens), each sent back for repair: a small part's note that paints something large (a twenty-fifth of the page or more) that colour; a plural note where under half of the look-alikes changed; a hollow or outline note where nothing there paints a border or fill.
- Small parts are a word list (hub, pin, knob, handle, dot, needle...) and plurals another. Position words ("right cards", "nav rows") are not read as all.
- Across 281 different fix notes kept from earlier runs, 2 read as a small part (both this page's) and 17 as a plural (`n270scan.mjs`). A few of those are odd fits, such as "pills read Week, Month, Year"; the check only fires when something changed in the note's target and most look-alikes did not.
- Tests: `packages/pipeline/tests/n270-fix-reach.test.ts` (15).

## Worth knowing
- **One replay each.** The fix behaviour is right in one build per page, which is not proof it always holds.
- **The new checks did not visibly fire here**: the reading and the brief got these right first, so the checks themselves are only covered by unit tests. The mixer's repair round came from other checks; I did not trace which.
- **Mixer's likeness fell 2.5**, and the picture is worse in ways not caused by this fix. The first build drew the six handles hollow despite "pale handles solid" (solid in n266). The thin bars stop about three quarters across, leaving the right of the strip empty, and two stray bars sit near the left. "time starts here" did not move the time this try (it did in n266). None traced; the first of these is a first-build difference.
- **Watchmaker's nav and logo moved** from where the notes were typed: logo about 80 px right of its note, as the first build spaced the nav across the page. Layout stays its lowest part at 72.
- **The word list is a list.** A small part not on it ("spindle gold") gets only the reading's rule, no check.
- A repaint that survives repair is reported, not put back, since a put-back would also lose the fix's other notes.
- The position-word rule was added after the live replays. It only narrows what counts as a plural and "tracks" is unaffected; not replayed.
- `npm run build` and `npm run typecheck` clean. `npm test`: 2 failed (init.test and library.test, same two as n266 to n269, no code of theirs changed), 2,536 passed before the last two added assertions.
