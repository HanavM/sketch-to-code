# N95: the quiet-build guard holds in live runs

Gap (n94, florist first attempt): a build turn wrote the page and then sat 6+ minutes with no stop; the n93 rule
(120 s with no progress after a write) never fired, and the run left no record of what the agent was doing.

## Why the live watch missed it
No log of that run survives, so this is from the code. After a write, the n93 rule counted *reply words* as progress
(streamed text deltas and whole text messages), and any tool call too: a build that keeps talking, or keeps
reading and globbing, held the turn open with the page already on disk. Only thinking and pings were caught.

## What was built
- **Work, not words, after a write** (`codegen.ts movesWorkOn`, session `lastWork()`): once a build has written
  the page, only tool calls, tool results, tool input being streamed and turn ends keep it going; reply text no
  longer does. 120 s without work ends the turn, page kept and verified (n93 path).
- **Reads alone are not building** (`turn-watch.ts BUILD_AFTER_WRITE_EDIT_MS`, 240 s): a build that wrote the page
  and then goes 4 minutes without another edit is ended the same way. An edit still being streamed counts as an
  edit (the session tracks which tool's input is streaming), so a long second Write is not cut mid-file.
- **Every hang leaves a record** (`watch-<tag>-<kind>.json` in the run folder, rewritten at every look, ~5 s):
  turn age, whether it wrote, seconds since activity / progress / work / edit, the last tool calls and the last 16
  kinds of agent message with how long ago. A turn that hangs again shows where it sat.

## Checks
- Unit: `n95-build-quiet-live.test.ts` (5 tests: words are progress but not work; tool input is work; talk after
  a write ends at 120 s; reads after a write end at 240 s, an edit keeps it going; message names).
- Scripted e2e `build-quiet-scripted.mjs`: PASS, quiet build ended at 7.2 s with page kept; its watch record says
  `stopping: the build wrote the page, then made no progress for 5 s`.
- Live: florist replayed word for word (same strokes, taps, notes as n94). No hang; the watch record shows the real
  stream (thinking, `system:thinking_tokens`, tool input, Edit) and the build ended on its own at 136 s.
