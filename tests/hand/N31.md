# n31: a box drawn turned stays turned; one note covers a group

Gaps from round 31 (n27): c3 stacked cards, the three cards drawn turned 3-7 degrees came out straight (one
read as a ring, one as freehand), and "3 tilted stacked cards" reached one card; a word fix then turned them
the wrong way. c2 night gallery, "thick gold frames on all 3" reached one frame.

## What was built
- **A box drawn turned is a turned box.** The ink is turned upright at the angle that fits it tightest; if it
  is then a box, and fits clearly better than upright, it is a box at that angle. The build is told its own
  size, centre and exact rotate(), and the page is checked (the built element's transform angle, same way
  round). Under 3 degrees a box counts as turned only inside a stack of clearly turned boxes, so a box drawn a
  little askew stays upright. The note label says "box", not "ring".
- **One note covers a group.** A note that names a count or "all/each/every/both" ("3 tilted stacked cards",
  "gold frames on all 3") covers every like-sized closed mark chained to the one it landed on; the thread shows
  "on these 3 boxes" before the build. Typed just off the group in empty space, it still joins the group.
- **Boxes drawn side by side keep their gap** (found while re-sketching c2: thick frames were added outside
  each drawn box and the frames touched). Checked on the page; the repair is told to keep the gap and put
  frames inside the drawn size.
