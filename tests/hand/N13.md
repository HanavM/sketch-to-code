# n13: a run never stalls silently (goal 2026-10-27)

## Built this step
- **Every codegen turn is watched.** A turn that hears nothing from the agent
  for 150 s, or a repair that would eat the minute the verify needs before the
  run cap, is ended with a plain reason (`packages/pipeline/src/turn-watch.ts`).
- **A stopped repair keeps the build.** The agent is shut (no late edits), the
  page on disk is verified once more, and the run finishes normally with its
  record, times and tokens; `result.json` says `repairStalled: <why>` and the
  turn in `sends.json` carries `stalled`. A stalled build turn fails fast with
  the reason instead of sitting until the 12-minute cap.
- **Every stage is written down as it happens** (`stages.jsonl` in the run
  folder, with ms since the run started), so a run that hangs or is stopped
  still says where it got to. n18's stalled runs left nothing to look at.

Tests: `packages/pipeline/tests/turn-watch.test.ts` (8). Build and typecheck
clean; full suite 1554 pass, 2 fail as before (root-only permission tests).
