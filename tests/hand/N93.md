# n93: a build that writes the page and then goes quiet is ended, the page kept and checked

## Gap found (n73 habits, n92 timesheet try 3)
The build turn wrote `App.tsx` (timesheet: at 156 s) and then nothing happened for 19 minutes (habits: 10+): no tool
call, no words, no end. The run was killed by hand, so it left no score, no record and no times. The watchdog did not
fire because a build turn counted every streamed message as "alive" (n21 let long thinking before the first Write
count, so a big Write is not cut off); after the Write, thinking and stream noise kept resetting it forever. And a build
the watchdog did stop threw the whole run away, even with the page already on disk.

## What was built (zero tokens)
- `turn-watch.ts`: once a build turn has written or edited a file, only real progress (a tool call, a tool result,
  reply words) keeps it going; 120 s without any (`BUILD_AFTER_WRITE_MS`, `S2C_AFTER_WRITE_MS` to change it) ends it
  with "the build wrote the page, then made no progress for N s (thinking is not progress)". Before its first write a
  build keeps the old rule (long thinking allowed, 150 s of total silence ends it).
- `run2.ts`: a build stopped that way keeps the page it wrote: the agent is closed (no edit can land later), the page
  is verified like any build, repairs (if needed) get a fresh agent with the reading and actions, and the record
  (`result.json`) says `buildStalled` and why. Times and tokens are written as usual.
- Scripted model (tests): a scripted build can report its tool calls and a turn that never returns ends when the
  agent is closed, like the real one, so a hung build can be tested at no cost.

## Evidence
- `packages/pipeline/tests/n93-build-quiet.test.ts` (5): the timesheet timeline (Write at 156 s, stream alive, no
  progress) is ended at 120 s; a build thinking before its first Write is left alone; a build still editing runs on.
  Fails before the change, passes after.
- `tests/e2e/build-quiet-scripted.mjs` (new, scripted, no tokens): the FAQ-section gesture whose build writes the file
