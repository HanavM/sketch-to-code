# n84: a colour note about small marks in rows colours only those marks

Round 35 e3 (workout log), n82/n83 first builds: the table card was typed "green dot at row end for 1-3, empty
ring for 4-5" (plus "all cards dark grey on near black page"). Both n83 tries painted the whole table card bright
green and gave rows 1-3 no dots; only the empty rings for rows 4-5 were built.

## Why
The note sat on the table card, so its colour word was read as the card's fill. Nothing told the build that a
note naming a small mark (dot, ring, tick) and some rows is about those marks, and nothing checked it.

## What was built (zero tokens)

  "red star on rows 2 and 4", "blue dot on every row") is read as row marks: which mark, its colour, filled or
  empty, which rows, which end of the row.
- Told to the build: each named row gets its mark at that end, centred on the row, its own element; the colour
  words colour only the marks; the card, table and text round them keep their own colour.
- Checked on the page: no big block is painted the marks' colour (unless another note asked for a block in it),
  and the named rows carry small marks in that colour.
