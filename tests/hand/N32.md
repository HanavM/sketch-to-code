# n32: one note for a group puts its contents on every member; a box noted as a quote mark is the glyph

Gaps from round 31 (n27, n31): c3 stacked cards, "3 tilted stacked cards, white plastik top left, •••• 4 digits
bottom" reached all three cards after n31 but the logo and digits were built on one card only. c5 spotlight
quote, a small box typed "big yellow quote mark" was built as a box; the n27 fix then built a closing ” where
the page opens the quote.

## What was built
- **A group note's contents go on every member.** Every closed mark a group note covers (its focus, or its
  whole cluster when the cluster is the group) is flagged; the build is told to put whatever the note names
  (words, logo, numbers, dots) on each one, in the same spot. Checked on the page: each thing the note put
  in the group must be built as many times as there are members (digits ignored, so different card numbers
  count as the same thing), and no member may be empty.
- **A box or ring noted as a quote mark is the glyph.** The opening “ unless the note says closing; built as
  text in the noted colour, no box behind it, sized so its ink fills the drawn spot (a quote mark's ink is
  about a third of its font size). Checked on the page: the right character is there, at about that size.
  Such a box is no longer a solid coloured box and no longer judged as a box-sized element.
- `replay.mjs`: replays an earlier hand sketch (same strokes, pens, notes; corrections and note drags left
  out) through the session, to measure a tool change with the sketch held still.
