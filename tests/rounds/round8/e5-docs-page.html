Offline sync

Lumen keeps a local copy of every board you open. Changes made offline are queued and merged when the device reconnects, using syncPolicy to resolve conflicts.

// enable sync for one board
const board = await lumen.boards.open('roadmap')
board.sync({ policy: 'last-write-wins', retry: 5 })
Note  Attachments over 25 MB are synced only on Wi-Fi.
