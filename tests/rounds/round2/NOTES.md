# Round 2 (harder than round 1: overlap, asymmetry, big type, dense everyday UI)

Targets: 5 creative (c1-c5) and 5 everyday (e1-e5) pages, written without tuning the tools to them
(n10), then auto-planned. Only three were built live: c2 outline bleed, c3 glass blobs, e3 settings.

| page | first build | best | what changed |
|---|---|---|---|
| c2 outline bleed | marks off the page edge broke capture (n11) | 59% (n36) | marks clamped on screen; drawn headline size carried through (was ~120px for a ~210px drawing); tight/wide letter spacing and edge bleeds said |
| c3 glass blobs | blobs faint, navy too dark, copy invented (n11) | 79% (n32b) | colours and card size said; quoted copy kept word for word |
| e3 settings | 6% on v2 although nearly identical (n11) | 36% on v3 | the likeness measure itself was fixed (n33): one global zoom/offset before scoring sparse white pages |
